- The run-to-run diff reports a one-ULP cross-platform change in `filtered` as `different`.

- The export's script is not packaged.
- `black`/`flake8` over `sensoryforge tests` fails (CI runs both).

## What holds

- **Tactile output is unchanged.** `SimulationEngine._run_neuron_stage` is a plain
  extraction of the old tail of `_run_pop_from_drive`, which A6b's re-simulation runs, so
  it is exactly the run's code. Bundles without `voltage_probes` and with
  `sparse_weights=False` are the 2.3.0 bundle (pinned by
  `tests/unit/test_bundle_voltage_probes.py`). The schema tags 2.4.0 and 2.5.0 are written only
  when the feature is used. The contract page section 7 says so. pressure-simulation-07
  cross-checked the sparse layout at `3eec647`.
- **The blind audit is walled.** The reader projects every file onto
  `audit/allowlist.py`, so `stimulus_config` (the declaration) never reaches a metric. The
  import wall test checks the static graph and a clean subprocess's `sys.modules`.
- **World-loader changes are invisible until used.**
  - `names.neutralise` rewrites only names that are not themselves fields. A typo stays an
    error (`'gaussian' has no fields ['sigmaa_mm']`).
  - The new layer-value check (F-398cbd1) rejects only values outside a field's domain.
  - `index_file_name` keeps `task_NNNN.jsonl` when no range is given (F-2f13dc9).
- **The page scripts insert data with `textContent` only**: there is no `innerHTML`. Links are
  built with `URLSearchParams`. The snapshot shim's request keys match the exporter's.
- **Docs.** Every row shipped its page, and the strict build is clean.

## Findings

High (wrong results on ordinary inputs):

1. **`core.data.time_grid` fails correct bundles at dt 0.1 or 0.2 ms.**
   `checks/data_checks.py:72` allows a step error of `1e-6 * dt`. The writer
   (`io/bundle.py:681`) stores `time_ms` as float32 `arange(T) * dt`, which rounds by more.
   - dt 0.1 ms over 3000 frames: 2935 steps "differ". dt 0.2 ms: 935. dt 1.0 and 0.5: none.
   - Effect: every entry fails, the gallery flags every entry `bad_data`, and
     `evaluate run` exits 1.
2. **The diff calls a one-ULP change `different` once a value reaches 2.**
   `diff/arrays.py` uses `FLOAT32_GOLDEN_ATOL = 2e-7` with `rtol = 0`. That tolerance was set for
   values below 1. `drive` and `filtered` are tens to hundreds of mA: one float32 step at 40 is
   3.8e-6. A Linux run against a macOS baseline is therefore `different` where the contract
   (section 14) promises `equivalent`. The same applies to the metric deltas.
3. **`core.run.saturation` always fails event-converter populations.** `level_crossing` and
   `sigma_delta` with `refractory_ms = 0` emit `floor(|d| / theta)` events in one step by
   design. The "at most one count per integration step" bound does not apply to them. An 8x8
   data set with both converters fails at 17,286 counts in a bin. That is every data set built
   the way pressure-simulation builds its own.
4. **The export's script is not packaged.** `pyproject.toml`'s package data lists
   `evaluate/server/static/*` but not `evaluate/export/static/*`, so `snapshot_shim.js` is
   missing from the wheel. `evaluate export` fails on any non-editable install. (Fixed in the
   review commit; the wheel now carries it.)

Medium:

5. **`core.run.determinism` hides real non-determinism.** When any population is unseeded,
   every fresh-build difference becomes a note, including differences in seeded populations
   (`engine_checks.py:85-96`). Whether an unseeded population differs at all also depends on
   the global RNG's history. When an earlier engine run left it where the second build finds
   it, the wiring comes out the same, no note is written, and
   `test_the_toy_data_set_with_three_channels` fails. That is the order dependency **F-5607a62**.
6. **Gallery `class_mismatch` goes silent when one class lacks a feature**
   (`server/gallery.py:493-519`). That class's `nanmedian` centre is NaN, so `argmin` picks it
   and the ratio is NaN. The entry is never flagged, and no reason is given.
7. **An unreadable bundle whose batch status is `ok` is flagged nowhere.** `bad_data` skips
   `core.data.readable` and assumes `did_not_run` covers it (`gallery.py:594`), but
   `did_not_run` fires only when the status is not `ok`.
8. **`run_diff` pairs entries in O(N²)** (`diff/run.py:74-75`: both dicts are rebuilt for
   every entry). 8000 entries take 5.9 s just to pair; 100k would take about 15 minutes.
9. **The pipeline skips `pipeline.json` on an unexpected exception.** A `TypeError` from a
   stage leaves `run_pipeline` with no `pipeline.json` written, and that stage still recorded
   as `ok` (`pipeline.py:45, 116-122`). This is the same defect R-A5 fixed in `jobs.py`.
10. **CI lint fails on the merged tree.**
    - `black --check sensoryforge tests`: `tests/unit/test_eval_gallery.py` would be
      reformatted.
    - `flake8 sensoryforge tests`: 53 lines, five of them in sources. The rest are long lines in
      tests and an unused import in `test_eval_server.py`.
    - Cause: `.flake8` excludes `.claude`, so inside a worktree a bare `flake8` checks nothing.
      Use `--exclude .git,build,site`.

Low:

11. **Sparse weights are not bit for bit for `-0.0`.** `encode_weights` keeps `dense != 0`,
    and decoding writes `+0.0`. No shipped builder writes `-0.0`, but an `imported` bank may,
    and the docstring promises bit for bit. Keep signed zeros
    (`nonzero | torch.signbit(dense)`). pressure-simulation's reader scatters the values, so it
    needs no change.
12. **`core.run.input_floor` claims more than it checks.** It re-runs from the stored
    `filtered` with the floor the bundle declares. Changing the declared floor 0.0 → 0.3 still
    passes, and only `rerun_matches` fails. Reword the title and the contract row to what it
    tests ("the neuron stage applies the declared floor") and point to `rerun_matches` for
    the data.
13. **`rerun_matches` drops the reason.** The re-run's notes (for example, unseeded membrane
    noise) are recorded but never reach the failure detail.
14. **The export's `--max-mb` limit covers only frames.** Traces, voltages and lists add to
    `spent` but are never compared with the limit (`export/build.py:228-232, 305-315`).
15. **A shared snapshot carries local paths.** `folder` and `checks.json`'s
    `inputs.dataset_dir` are embedded as given, and the pipeline passes an absolute path.
    Write the folder's name only.
16. **Gallery slips.**
    - Unticking every signal shows everything (`gallery.js:7`).
    - The docstring's z-scale floor names the whole data set's std, but the code uses the
      group's.
    - `saturated` is a mean count per bin per unit, not "a fraction of bins".
17. **One scale-test assertion is a tautology.** `tests/scale/test_pipeline_small.py` compares
    `["train"]` with `["train"]`. The `measured(...)` equality after it is the real test.
18. **A plugin can shadow an alias** (no change; documented here). If a plugin registers a
    field named `sigma`, then `sigma` stops being an alias of `sigma_mm`, and a world written
    `sigma:` fails to load with "has no fields". That failure is loud, never silent, and
    `alias_table()` shows the current table.

## Required changes (row Af)

Make each change with a test that fails before it, unless the item says otherwise.

1. **Time grid** (finding 1). Compare `np.diff(time)` with the steps of
   `np.arange(T, dtype=float32) * dt`. Or allow a tolerance of a few float32 ULPs of
   `max(|time|)`. Test at dt 0.1, 0.2 and 1.0 with T in the thousands.
2. **Diff tolerance** (finding 2). Add a relative term of two float32 ULPs (`rtol = 2**-22`)
   to the float comparison and the metric deltas. Leave the integer readouts exact. Update
   contract section 14 and `docs/developer_guide/diff_stage.md`. Test with `nextafter` at
   0.5, 3 and 40.
3. **Saturation** (finding 3). The bound applies to spiking neuron models.
   - A population whose model is an event converter (`neurons/event_encoders.py`) has no
     per-step bound when `refractory_ms = 0`; report it as not tested, with a note.
   - With `refractory_ms > 0`, the bound is `ceil(steps / R)`.
   - Test on an 8x8 data set with `level_crossing` and `sigma_delta`. Update the contract
     row in section 13.1.
4. **Determinism** (finding 5). Compare the fresh build on the seeded populations only. Every
   difference there is a failure. Always name unseeded populations in the note, whether or not
   they differed. Keep the contract row's meaning. Closes F-5607a62; check that
   `test_eval_checks.py` passes after the earlier test files in one run.
5. **Gallery** (findings 6, 7, 16).
   - Compute class centres over the features each one has and skip NaN distances.
   - Flag `core.data.readable` failures under `bad_data` whatever the batch status.
   - Unticking every signal shows none.
   - Fix the two docstrings.
6. **Diff pairing** (finding 8). Build the two entry dicts once.
7. **Pipeline** (finding 9). Whatever a stage raises, mark the stage failed, write
   `pipeline.json` and re-raise any error outside `_STAGE_ERRORS`.
8. **Sparse signed zeros** (finding 11). Keep `-0.0` entries. Test the round trip with
   `torch.signbit`.
9. **Smaller fixes** (findings 12-15, 17).
   - Reword the input-floor check.
   - Carry the re-run's notes into the `rerun_matches` failure detail.
   - Count every recorded answer against `--max-mb`.
   - Write the folder's name, not its path, in a snapshot.
   - Drop the tautological assertion.
10. **Lint** (finding 10). Make `black --check sensoryforge tests` and
    `flake8 --exclude .git,build,site sensoryforge tests` clean.

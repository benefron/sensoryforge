## Findings

Ranked most severe first. "Reproduced" means run here, in a scratch folder.

1. **`agents setup` installs or removes the routing hook in the wrong project (reproduced).**
   `cli.py::cmd_agents` takes the project as `target.resolve().parent.parent`, which is right
   only when the style file is `<project>/.sensoryforge/agents.yml`. With `--path style.yml`
   the hook lands in the project's parent's `.claude/settings.local.json`; with
   `$SENSORYFORGE_AGENTS_CONFIG` pointing elsewhere, or a style file found in an ancestor
   folder, it lands there. `detect_environment(root)` looks in the same wrong folder, and
   `--hooks no` removes a hook from it. A user's unrelated folder is edited and their
   project gets no hook.
2. **`set_hook` raises `AttributeError` on settings shaped in a way it does not expect
   (reproduced).** `agents/style.py::set_hook`: `{"hooks": []}`, or a hook entry that is a
   string, crashes; `cmd_agents` catches only `ValueError`/`OSError`, so the user gets a
   traceback after the style file is already saved. An event whose value is a dict is
   silently replaced, and a user group with `"hooks": []` is dropped.
3. **Six skill findings from B9 failed again** (this review's run, below): the
   ground-assumptions skill is not loaded for a value with no unit or far out of range
   (F-725b89c, `ground.no-unit`, `ground.out-of-range`); under "carry on" the workflow fills
   a realistic fingertip's sizes and timings from memory as labelled proposals (F-c386cd4,
   `flow.realistic-fingertip`); "whichever packs are right" makes the agent pick
   `core,tactile` itself (F-48955f0, `eval.which-packs`); checking a world does not load
   design-world (F-796f541, `world.zero-sigma`); the agent asserts a GPU "won't help"
   (F-4107108, `run.how-long-gpu`); a session budget is named as a contingency, not used to
   split the plan (F-d1056b6, `plan.session-budget`). Each has a one-sentence fix in a skill's
   description or body. F-a920f84's editor half (`export-generic.which-editor`, asked
   nothing) failed again too; its markers half passed this time.
4. **Export never removes a skill a later release drops** (read, not reproduced).
   `agents/install.py::install`/`check` walk only the current release's skills, so a renamed
   or removed `sensoryforge-*` folder stays in `.claude/skills/` and keeps loading, while
   `export --check` says everything is current.
5. **Low, safe failures, deferred.** The Cursor rule `.cursor/rules/sensoryforge.mdc` is
   replaced without checking its do-not-edit header (the name is SensoryForge's own).
   `merge_section` matches marker lines inside a fenced code block and fails on a file that
   starts with a byte-order mark; both refuse rather than clobber. The routing hook runs
   `sys.executable` by absolute path, so it errors on every prompt once that environment is
   removed (Claude Code shows the error and goes on). `describe` text mode prints nothing
   for `--section formats` and leaves out `numeric_distributions`; `validate --json` does
   not report an unknown name under `plugins:`.
6. **Not this phase's to fix, recorded.** `developer_guide/architecture_notes.md` (moved out
   of `CLAUDE.md` in B2) carries about 35 ledger ids and Phase/Wave labels, which Ben's
   answer to D1's Q2 (D-41f73ea) removes from public pages; D1b-C does that pass. The
   exports and instruction files were checked against each tool's documentation, not run
   inside Copilot, Cursor or Codex (F-4f3a248, F-d3d0a2b); that needs Ben with those tools.

## Required changes (row Bf, Sonnet, session S22b; the phase merges at its end)

1. **The hook goes in the project the user is in** (finding 1). `cmd_agents` takes the
   project from the current folder, or from a new `--dest` (as `install`/`export` have),
   never from where the style file is; `detect_environment` and `set_hook` use that folder.
   Tests: `--path` elsewhere, `$SENSORYFORGE_AGENTS_CONFIG` elsewhere and a style file in a
   parent folder each leave the parent untouched and write the project's
   `.claude/settings.local.json`.
2. **`set_hook` refuses what it does not understand** (finding 2). A `hooks` that is not a
   mapping, an event value that is not a list, or an entry or group that is not a mapping
   raises `ValueError` naming the path and the file; it keeps a user group with an empty
   `hooks` list. `cmd_agents` checks the settings file before saving the style, so a refusal
   leaves both files as they were. Tests for each shape.
3. **Export lists and removes skills a release dropped** (finding 4). `check` reports a
   `sensoryforge-*` skill folder (or file, per target) that this release does not ship and
   whose file carries the generated header as `stale`; `install` removes exactly those and
   prints `removed`. A folder without the header is reported, never removed. Tests.
4. **Skill wording, one sentence each** (finding 3), then re-run those scenarios
   (`run.py --scenario ...`) and record the result:
   - `sensoryforge-ground-assumptions` description: also for a number given with no unit or
     far outside the range the skill or world states (F-725b89c).
   - `sensoryforge-workflow` body: a proposal file of physical values from memory is
     inventing; at any pace, ask for them or offer the grounding skill (F-c386cd4).
   - `sensoryforge-evaluate` body: a request for "the right packs" leaves the choice with
     the user: run `core`, say which other packs exist, and ask (F-48955f0).
   - `sensoryforge-design-world` description: also for checking or validating an existing
     world file (F-796f541).
   - `sensoryforge-run-simulation` body: a device's effect on time is known only by timing
     one entry on it; never claim it (F-4107108).
   - `sensoryforge-design-and-plan` step 4: with a session budget, split the plan into
     sessions and say where each stops even when sizes are still open (F-d1056b6).
   - the generic prompt: "my editor" names the user's tool; ask which (F-a920f84, its
     editor half).
   Regenerate `docs/agents/skills_reference.md`; the glossary and names tests must pass.
5. **Docs.** `agent_setup.md` (where the hook goes, `--dest`, what a malformed settings file
   gives), `agent_export.md` (stale skills are removed only when generated). Close
   F-725b89c, F-c386cd4, F-48955f0, F-796f541, F-4107108, F-d1056b6 only for scenarios that
   pass in the re-run; `Refs:` the rest.
